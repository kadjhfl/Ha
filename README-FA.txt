هەوراز - پروژه ساخت APK اندروید

این پروژه نسخه فعلی آفلاین هەوراز را داخل یک برنامه اندرویدی قرار می‌دهد.
برنامه بدون اینترنت اجرا می‌شود و اطلاعات را روی همان گوشی نگه می‌دارد.
اطلاعات بین گوشی‌ها و لپ‌تاپ همگام نمی‌شود.

برای ساخت APK با GitHub Actions:
1) محتویات این پوشه را در ریشه مخزن GitHub خود بارگذاری کنید؛ پوشه .github نیز باید در ریشه مخزن قرار بگیرد.
2) در GitHub وارد تب Actions شوید.
3) گردش کار Build HAWRAZ APK را انتخاب کنید و Run workflow را بزنید.
4) پس از پایان موفق، از صفحه اجرای workflow بخش Artifacts فایل HAWRAZ-Android-APK را دانلود کنید.
5) ZIP دانلودشده را باز کنید و app-debug.apk را روی گوشی نصب کنید.

نکته امنیتی: رمز داخل نسخه فعلی فقط یک قفل ساده سمت برنامه است و امنیت واقعی اطلاعات را تضمین نمی‌کند. برای اطلاعات واقعی مشتریان از نسخه بدون حفاظت سروری استفاده نکنید.
